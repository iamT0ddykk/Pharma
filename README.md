# 💊 Pharma

> Uma landing page moderna para uma farmácia, desenvolvida com **HTML, CSS e JavaScript**.

O **Pharma** foi criado para praticar o desenvolvimento de interfaces web, focando na construção de uma página inicial com design limpo, organização de conteúdo e uma boa experiência de navegação.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar a criação de **landing pages**, aplicando conceitos de estruturação de páginas, estilização responsiva e interatividade utilizando apenas tecnologias nativas da web.

---

## ✨ Funcionalidades

* 💊 Landing page para uma farmácia
* 📱 Layout responsivo
* 🎨 Interface moderna e organizada
* ⚡ Navegação simples e intuitiva
* 🚫 Desenvolvido sem frameworks

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/iamT0ddykk/pharma.git
```

2. Entre na pasta do projeto:

```bash
cd pharma
```

3. Abra o arquivo `index.html` em qualquer navegador.
